GitHub Pages review checklist

Use this list to verify the deployment before treating the page as production-ready.

01
Entry point
Confirm root index.html is included in the published Pages source.
02
Pages source
In Settings → Pages, verify the selected branch and folder match the intended publish root.
03
Custom domain
Verify the custom domain and HTTPS certificate in Pages settings; do not infer DNS health from this page.
04
Actions result
Review the latest Pages build/deployment run and confirm its actual status and logs.
05
Mobile rendering
Test the published URL in iPhone Safari at narrow viewport widths.
06
Migration safety
Keep source repositories intact; review every migration in a separate branch and pull request.

Important: a successful HTTP response only proves that the URL responds. It does not prove the latest Git commit has been deployed, the custom domain is configured correctly, or all links and assets work.
